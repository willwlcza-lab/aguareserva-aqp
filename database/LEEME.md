# Base de datos

- `aguareserva_es_inicial.dump`: respaldo Custom de una instalación vacía, con revisión Alembic `fuentes20261125`. No contiene cuentas ni hogares.
- `schema.sql`: estructura para estudiar; no sustituye el historial y estado de Alembic.
- Para una instalación nueva, sigue `docs/GUIA_INSTALACION.html` y ejecuta las migraciones contra la base `aguareserva`.
- Para llevar tus datos al docente, sigue `docs/RESPALDO_PGADMIN.html` y agrega aquí el respaldo creado en tu PC.
